# Demo walkthrough

1. Configure MongoDB and `server/.env`, then run `npm install`, `npm run seed`, and `npm run dev`.
2. Sign in as `customer@demo.com` with password `Demo@1234`.
3. Post a plumber or electrician job and review the ranked match explanations.
4. Sign in as `worker1@demo.com` with the same password and respond to the pending request.
5. Return to the customer account to confirm the counter or complete accepted work.

Seed accounts are for local development only. Never deploy them to a public production service.
