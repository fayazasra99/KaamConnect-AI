# KaamConnect AI — Local demo

A responsive, browser-based prototype of a local services marketplace. It includes worker search and filtering, service categories, booking requests with hourly estimates, booking history saved in browser storage, role preview, and a guided service assistant.

## Run it

Open [index.html](index.html) in a modern browser. No installation or build step is required. Demo bookings are stored in that browser's local storage.

## Notes

This is a frontend demo with sample professionals. It does not include live user accounts, a server/database, real AI, real Razorpay payments, or public hosting. Those require backend services and deployment configuration.
